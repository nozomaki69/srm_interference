# 相手PAN負荷 80% における干渉判定 AUC のまとめ (single-query / multi-query)

論文で使っている「相手PAN負荷 80%」断面の、9 通りの帯域ペア (自PAN 50/100/200 kbps × 相手PAN 50/100/200 kbps) について、3 手法 (Proposed / ΔPER only / RSSI only) × 2 測定モード (single-query = simultaneous, multi-query = sequential) の AUC を表にした。

## データ元と断面の定義

- single-query: `plots/detection_lines/auc_single_plotted_values.csv`
- multi-query: `plots/detection_lines_sequential/auc_multi_plotted_values.csv`
- どちらも `plot_detection_lines.py` が `auc_*_grid_otherload080.pdf` / `auc_modecompare_*_grid_otherload080.pdf` に描いた値そのもの。`other_load_percent == 80` の行を抜き出した (各モード 135 行 = 9 ペア × 3 手法 × 自負荷 5 点)。
- 自/相手の読み替えは `own_other()` による (検知している側が「自」。対称ペアは PAN1 側のみ)。
- 各点は干渉あり 100 Seed / 干渉なし 100 Seed の AUC。[ ] はブートストラップ 1000 回の 95% 信頼区間。
- PAN 間距離は帯域ペアごとに固定: 50 kbps を含むペア 1500 m、100vs100・100vs200 は 1300 m、200vs200 は 1100 m。
- このファイルは scratchpad の一回限りのスクリプトで CSV から機械的に生成した。CSV を作り直したら値は変わる。
