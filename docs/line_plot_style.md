# 折れ線グラフの体裁変更

折れ線グラフ (`script/plot_detection_lines.py`) の見た目だけを変える。
AUC の値・断面・系列の選び方は一切変えない。

## 1. 何を変えるか

| 項目 | 変更前 | 変更後 |
|---|---|---|
| ΔPER only の線種 | 破線 `--` | 長い破線 `(0, (8, 4))` |
| RSSI only の線種 | 点線 `:` | 丸い点の列 `(0, (0.1, 3.0))` + 丸キャップ |
| 点 (マーカー) | 塗りつぶし | **白抜き** (面は白、縁は線の色) |
| 3手法を重ねた図の凡例 | 色 3項目 + 線種 3項目 (計6) | **3×3 の行列** (行 = 手法、列 = 相手帯域) |

### 線種

変更前の `--` と `:` は、線幅 2.0 だと破線の間隔が近く、印刷・縮小すると区別しにくい。
片方を「長い破線」、もう片方を「丸い点の列」にして、線の形そのものが違うようにする。

- ΔPER only: 線分 8 pt・間隔 4 pt の長い破線
- RSSI only: 長さほぼ 0 の線分を丸キャップで描き、直径 = 線幅の点を 3 pt 間隔で並べる

提案手法は実線のまま。

### 白抜きの点

マーカーの面を白 (`markerfacecolor="white"`)、縁を線の色にする。縁の太さは 1.8。
白抜きにすると縁だけで形 (○□△) を読むことになるので、大きさを 6 → 8 に上げる。
髭 (信頼区間) の上に点が来るよう、線と点は髭より手前に描く。

モード比較図 (`--mode compare`) も同じ `_draw_series()` を通るので白抜きになる。

### 3×3 の行列凡例

変更前の凡例は「色 (帯域) 3項目 + 線種 (手法) 3項目」で、6本の線があるように見えた。
実際の線は 3手法 × 3帯域 = 9 本なので、9 本をそのまま行列で並べる。

```
              (列1)        (列2)         (列3)
Proposed      ─○─ 50 kbps  ─□─ 100 kbps  ─△─ 200 kbps
ΔPER only     ‐○‐ 50 kbps  ‐□‐ 100 kbps  ‐△‐ 200 kbps
RSSI only     ·○· 50 kbps  ·□· 100 kbps  ·△· 200 kbps
```

- 1列目は手法名だけ (線の見本なし) の行見出し
- 各セルの見本は、図中の線と同じ 色・線種・白抜きマーカー
- matplotlib の凡例は列方向に詰めるので、`ncol=4` で
  [見出し3つ] → [50 kbps の3手法] → [100 kbps の3手法] → [200 kbps の3手法] の順に渡す
- 凡例が大きくなり、軸の中に置くと線に重なるので、**軸の上側の外**に置く
  (単独図・3パネル図とも)

手法が1つだけの図 (`*_proposed` / `*_dper` / `*_rssi`) は、線種の軸が無いので
帯域3項目の凡例のまま。ただし、変更前は凡例の見本が常に実線で、
dper / rssi の図では図中の線種と食い違っていたので、見本の線種を図中に揃える。

## 2. 変えないもの

- AUC の値、断面 (相手負荷 100%)、own/other の読み替え (`own_other()`)
- y 軸の決め方 (`choose_ylim()`)。レビューで指摘した「信頼区間の髭が枠外に切れる」
  問題はここでは直していない
- 出力ファイル名・枚数 (16枚 + `auc_plotted_values.csv`)

## 3. 実行

```sh
python3 script/plot_detection_lines.py                 # single-query
python3 script/plot_detection_lines.py --mode sequential
python3 script/plot_detection_lines.py --mode compare
```

計算機では `./script/plot_figures.sh` が上の3つを呼ぶ。
