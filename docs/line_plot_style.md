# 折れ線グラフの体裁変更

折れ線グラフ (`script/plot_detection_lines.py`) の見た目だけを変える。
AUC の値・断面・系列の選び方は一切変えない。

## 1. 何を変えるか

| 項目 | 変更前 | 変更後 |
|---|---|---|
| ΔPER only の線種 | 破線 `--` | 長い破線 `(0, (8, 4))` |
| RSSI only の線種 | 点線 `:` | 丸い点の列 `(0, (0.1, 3.0))` + 丸キャップ |
| 点 (マーカー) | 塗りつぶし | **白抜き** (面は白、縁は線の色) |
| 3手法を重ねた図の凡例 | 色 3項目 + 線種 3項目 (計6) | **3×3 の行列** (行 = 手法、列 = 相手帯域) |
| 点と髭の横位置 | 系列ごとに 1.2% ずつずらす | **ずらさない** (本来の負荷の位置) |
| グリッド線 | 縦・横 | **横線だけ** (折れ線の全図。ROC 曲線は縦横のまま) |

### 線種

変更前の `--` と `:` は、線幅 2.0 だと破線の間隔が近く、印刷・縮小すると区別しにくい。
片方を「長い破線」、もう片方を「丸い点の列」にして、線の形そのものが違うようにする。

- ΔPER only: 線分 8 pt・間隔 4 pt の長い破線
- RSSI only: 長さほぼ 0 の線分を丸キャップで描き、直径 = 線幅の点を 3 pt 間隔で並べる

提案手法は実線のまま。

### 白抜きの点

マーカーの面を白 (`markerfacecolor="white"`)、縁を線の色にする。縁の太さは 1.8。
白抜きにすると縁だけで形 (○□△) を読むことになるので、大きさを 6 → 8 に上げる。
髭 (信頼区間) の上に点が来るよう、線と点は髭より手前に描く。

モード比較図 (`--mode compare`) も同じ `_draw_series()` を通るので白抜きになる。

### 3×3 の行列凡例

変更前の凡例は「色 (帯域) 3項目 + 線種 (手法) 3項目」で、6本の線があるように見えた。
実際の線は 3手法 × 3帯域 = 9 本なので、9 本をそのまま行列で並べる。

```
              (列1)        (列2)         (列3)
Proposed      ─○─ 50 kbps  ─□─ 100 kbps  ─△─ 200 kbps
ΔPER only     ‐○‐ 50 kbps  ‐□‐ 100 kbps  ‐△‐ 200 kbps
RSSI only     ·○· 50 kbps  ·□· 100 kbps  ·△· 200 kbps
```

- 1列目は手法名だけ (線の見本なし) の行見出し
- 各セルの見本は、図中の線と同じ 色・線種・白抜きマーカー
- matplotlib の凡例は列方向に詰めるので、`ncol=4` で
  [見出し3つ] → [50 kbps の3手法] → [100 kbps の3手法] → [200 kbps の3手法] の順に渡す
- 凡例が大きくなり、軸の中に置くと線に重なるので、**軸の上側の外**に置く
  (単独図・3パネル図とも)

手法が1つだけの図 (`*_proposed` / `*_dper` / `*_rssi`) は、線種の軸が無いので
帯域3項目の凡例のまま。ただし、変更前は凡例の見本が常に実線で、
dper / rssi の図では図中の線種と食い違っていたので、見本の線種を図中に揃える。

### 横へのずらし (dodge) をやめる

髭があるとき、`icc` は同じ負荷の点と髭が真上に重ならないよう、系列ごとに横へ
1.2% ずつ (9本なら ±4.8%) ずらしていた。重なりは減るが、点が本来の負荷
(20, 40, ... %) の位置から外れて見える。そこで `CI_DODGE = 0.0` にして、
すべての点と髭を本来の負荷の位置に描く。

代わりに、同じ負荷で値の近い系列は点と髭が重なる。点は白抜きで髭より手前に
描くので、点の形 (○□△) と縁の色は読める。重なりが読みにくければ
`CI_DODGE` を 1.2 に戻すだけで元の描き方になる。

### 3×3 グリッド図 (`auc_grid.pdf`)

3手法を重ねた図 (`auc_*_compare.pdf`) は、1パネルに 3手法 × 3相手帯域 = 9 本の線が乗り、
ずらしを止めたことで点と髭も重なって読みにくい。そこで、帯域の組を**位置**で分けた
3×3 の小さな図 (small multiples) を足す。

```
              Other 50 kbps   Other 100 kbps   Other 200 kbps
Own 50 kbps    [P  D  R]        [P  D  R]         [P  D  R]
Own 100 kbps   [P  D  R]        [P  D  R]         [P  D  R]
Own 200 kbps   [P  D  R]        [P  D  R]         [P  D  R]
```

- 行 = 自帯域、列 = 相手帯域。1パネルの線は 3手法の 3本だけ
- 帯域は位置で読めるので、**色を手法に割り当てる** (Proposed 青 / ΔPER only 橙 / RSSI only 緑)。
  線種 (実線 / 長い破線 / 丸点) とマーカー (○ / □ / △) も手法ごとに変え、色に頼らず読めるようにする
- 横軸・縦軸は全パネル共通 (`choose_ylim()` の値)。軸ラベルも行見出し・列見出しも入れない
  (並び順は上の表のとおりで、図のキャプションで説明する)
- 凡例は手法の 3 項目を図の上に 1 行
- 点・髭の体裁 (白抜き、ずらし無し) は他の図と同じ `_draw_series()` を使う
- 出力: `plots/detection_lines/auc_grid.pdf` (single-query)、
  `plots/detection_lines_sequential/auc_grid.pdf` (multi-query)。モード比較には作らない

既存の 16 枚はそのまま残す。

### 信頼区間の髭が枠外に切れる問題を直す

y 軸の下端 (`choose_ylim()`) を AUC の点だけで決めていたので、点は枠内でも
髭の下端 (ブートストラップ 95% 区間の下限) が枠の外に出て切れていた
(例: single-query の ΔPER only、自帯域 200・相手 50 kbps・自負荷 100% は
点 0.47 / 下限 0.39 で、軸 0.4 から下が切れた)。
髭を描くときは、**区間の下限も含めた最小値**から下端を決める。0.1 刻みで切り下げ、
全図共通にする規則は変えない。

### 凡例の文字を大きくする

`LEGEND_FONTSIZE` を 18 → 22 にする (折れ線の全図)。

### モード比較図 (`detection_lines_mode_compare/`)

- **色を変える**。この図の色は相手帯域を表すが、3手法の図で使っている
  青・橙・緑 (グリッド図では手法の色) と同じだったので紛らわしかった。
  **濃い金 (50 kbps) / マゼンタ (100 kbps) / 黒 (200 kbps)** にして、他の図のどの色とも
  重ならず、互いにもはっきり違うようにする (最初に試した紫の濃淡は見分けにくかった)
- **縦長にする**。横軸は負荷の5点だけなので横幅を詰める
  (単独図 7.2×5.8 → 5.4×6.6 インチ、3パネル 19×5.8 → 14×6.6、横軸の余白も左右 6% に)
- **凡例を 2×3 の行列にまとめて、図の上に置く**。`icc` は
  「50 kbps (single-query)」のような長いラベルを6つ縦に並べていた。
  行 = 測定モード (single-query / multi-query)、列 = 相手帯域にすると、
  各セルのラベルは「50 kbps」だけで済む

```
                (列1)        (列2)         (列3)
single-query    ─○─ 50 kbps  ─□─ 100 kbps  ─△─ 200 kbps
multi-query     ·○· 50 kbps  ·□· 100 kbps  ·△· 200 kbps
```

単独図は幅が狭いので、凡例を縦向き (列 = モード、行 = 相手帯域) にして図の幅に収める。

## 2. 変えないもの

- AUC の値、断面 (相手負荷 100%)、own/other の読み替え (`own_other()`)
- 出力ファイル名・枚数 (16枚 + `auc_plotted_values.csv`)

## 3. 実行

```sh
python3 script/plot_detection_lines.py                 # single-query
python3 script/plot_detection_lines.py --mode sequential
python3 script/plot_detection_lines.py --mode compare
```

計算機では `./script/plot_figures.sh` が上の3つを呼ぶ。
